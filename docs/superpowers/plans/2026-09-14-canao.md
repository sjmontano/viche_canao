# VICHE CANAO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir sitio informativo + catálogo Astro SSG bilingüe-ready para Viche CANAO, editable en /admin.

**Architecture:** Astro SSG con Content Collections tipadas con Zod, componentes islands mínimas, imágenes optimizadas a AVIF, deploy Cloudflare Pages. Decap CMS commitea Markdown y dispara rebuild.

**Tech Stack:** Astro ^4.16.0, Tailwind ^3.4.1, TypeScript strict, Decap CMS ^3.1.2, vitest ^2.1.0, @astrojs/check ^0.9.0, Cloudflare Pages.

## Global Constraints

- Node 20 LTS mínimo, npm 10 mínimo.
- JS cliente <100KB total, CSS <50KB.
- Colores exactos: fondo #0F0D0B, superficie #1A1512, ámbar #D9A441, caña #7FB069, texto #F5EFE6, muted #A89C8D.
- Tipos: Fraunces display + Inter cuerpo vía Google Fonts con display=swap.
- LCP <2.5s 4G, CLS <0.1, Lighthouse ≥95 perf/a11y/SEO.
- Español día 1, estructura `src/i18n/es.json`, rutas `/en/` fase 2.
- +18 visible en Hero y Footer, sin promesas medicinales.
- Fotos fuente en `Recrusos/CANAO X PENUMBRA-*/` y `Recrusos/BOCA DE AMÉ JUAN SILVA-*/`, salida AVIF <200KB, hero <400KB.
- WhatsApp CTA con mensaje prellenado, número desde `src/consts.ts` WHATSAPP_NUMBER.
- YAGNI: sin carrito, sin pagos, sin blog complejo, sin backend.
